# Example: ZKP Non-Fungible Tokens with Zeto

This example demonstrates privacy-preserving non-fungible tokens (NFTs) using [Zeto](https://github.com/hyperledger-labs/zeto) on Paladin, passing a single NFT between owners on each of the three nodes.

See the [tutorial](https://LFDT-Paladin.github.io/paladin/head/tutorials/zkp-nft/) for a detailed explanation.

## Pre-requisites

Run the common [setup steps](../README.md) before running the example.

## Running the example

```shell
npm install           # install dependencies
npm run copy-abi      # copy relevant ABIs
npm run start         # run the example
```
